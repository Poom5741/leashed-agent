TRUST LAYER · v2 · design exploration
Four visual directions for the Leashed Agent Platform.

Each variant is a complete HTML mockup of the three pages (Agents list, Passbook, Marketplace). Open them side-by-side to compare feel. None of these touch production code yet.

A
Paper Ledger Book
Variant A · serif + ink
The v1 baseline refined: Fraunces + IBM Plex Mono + Caveat signature. Paper bg, ink rules, watermark, perforation between leaves, stamp motifs. Most familiar.
Open variant
B
Modern Ink
Variant B · minimal Japanese ledger
Editorial restraint. Shippori Mincho serif, vertical-rule layout, single ink color, generous whitespace. Lets the data breathe.
Open variant
C
Neo-brutalist Trust Ledger
Variant C · heavy borders + accents
Loud. 3-px black rules, no rounded edges, hot-pink + cyan on cream, monospace everywhere, chunky offset shadows. Visible from across the room.
Open variant
D
Archival Blueprint
Variant D · technical drafting
Cool gray-cyan paper. Hairline grids, drafting-blue ink, schematic annotations, corner crosshairs, ruler tick marks. Reads as an auditor's working document.
Open variant
